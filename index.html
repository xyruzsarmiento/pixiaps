Connection guide

Pick your platform. Get in fast.

No bloated setup guide. Choose your device and follow the exact steps below. If something fails, the Pixia Discord support team can help you directly.

iPhone / iPad

Connect with Surge 5

Use a downloadable profile and let Surge handle the connection.

01

Install Surge 5

Download Surge 5 from the App Store and open it.

02

Open the default profile

Press OK, then select Default.conf.

03

Import the Pixia profile

Choose IMPORT → Download Profile from URL.

https://pixiagtps.vercel.app/api/ios/852
04

Enable and launch

Press SETUP, allow the VPN profile, then open Growtopia and log in.

Android · no root

Connect with PowerTunnel

A lightweight route that works without rooting your phone.

01

Install PowerTunnel

Download the latest Android release from the official GitHub repository.

https://github.com/krlvm/powertunnel-android/releases
02

Open Hosts settings

Open PowerTunnel, enter the menu, then choose Hosts settings.

03

Paste the Pixia hosts URL

https://pixiagtps.vercel.app/api/android/852
04

Connect

Tap Connect, keep PowerTunnel active, then launch Growtopia.

PC / Laptop

Edit the Windows hosts file

A direct desktop setup using the native Windows hosts file.

01

Open the hosts directory

Press Win + R, then open:

C:\Windows\System32\drivers\etc
02

Edit as administrator

Open the hosts file with administrator privileges and add the Pixia routes.

91.134.85.13 growtopia1.com 91.134.85.13 growtopia2.com 91.134.85.13 www.growtopia1.com 91.134.85.13 www.growtopia2.com
03

Save and launch

Save the file, close the editor, then launch Growtopia.
